Politique de Confidentialité - DataHub

Dernière mise à jour : 30 juillet 2026

1. Collecte des données

DataHub collecte uniquement les données nécessaires au fonctionnement du service :

  • Données d'authentification (tokens API)
  • Journal d'audit des opérations effectuées
  • Données stockées dans les tables de la base de données
  • Fichiers et artefacts créés par les utilisateurs

2. Utilisation des données

Les données collectées sont utilisées pour :

  • Authentifier les utilisateurs et les agents
  • Journaliser les opérations pour audit et sécurité
  • Fournir les fonctionnalités du service
  • Générer des artefacts et rapports demandés

3. Partage des données

DataHub ne partage pas vos données avec des tiers. Vos données restent sur nos serveurs et sont accessibles uniquement via les API authentifiées.

4. Sécurité des données

Nous mettons en œuvre des mesures de sécurité appropriées pour protéger vos données :

  • Authentification par token Bearer
  • Chiffrement des communications (HTTPS)
  • Journal d'audit complet des opérations
  • Contrôle d'accès basé sur les scopes

5. Droits des utilisateurs

Vous avez le droit de :

  • Accéder à vos données via les API
  • Modifier ou supprimer vos données
  • Exporter vos données
  • Demander la suppression de votre compte

6. Conservation des données

Les données sont conservées tant que votre compte est actif. Les données d'audit sont conservées pendant 90 jours maximum.

7. Contact

Pour toute question concernant cette politique de confidentialité, contactez-nous à :

Email : admin@agent.co-ned.com

Site web : https://agent.co-ned.com

8. Modifications

Nous nous réservons le droit de modifier cette politique de confidentialité. Les modifications seront publiées sur cette page avec la date de mise à jour.
