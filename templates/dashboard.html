🧠 Skill orchestrateur — Porte d'entrée unique

Rôle critique : L'orchestrateur est la seule porte d'entrée pour tous les agents (ChatGPT, Claude, etc.). Aucun agent ne peut accéder directement à la base de données ou aux ressources internes.
Fonctionnement :
  • L'agent transmet sa demande à l'orchestrateur
  • L'orchestrateur analyse l'action demandée
  • Il recherche le sous-skill compétent correspondant
  • Il délègue l'exécution si la compétence existe
  • Sinon, l'agent répond : "Je ne dispose d'aucune compétence permettant d'effectuer cette action."
⚠️ Sans orchestrateur actif, les agents n'ont AUCUN ACCÈS au système.
Formats acceptés : fichier .md ou dossier zippé .zip

🧩 Skill de compétence — Délégation par l'orchestrateur

Rôle : Les compétences sont des sous-skills que l'orchestrateur peut déléguer pour exécuter des actions spécifiques.
Mécanisme :
  • L'orchestrateur analyse la demande de l'utilisateur
  • Il recherche parmi les compétences installées celle qui correspond
  • Il délègue l'exécution au sous-skill compétent
  • Le résultat est retourné à l'agent puis à l'utilisateur
💡 Une compétence ne fonctionne que si elle est importée et si l'orchestrateur est actif.
Formats acceptés : fichier .md ou dossier zippé .zip
